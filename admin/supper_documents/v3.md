## 1. Authentication Flow Overview

```
┌─────────────────────────────────────────────────────────────┐
│                    AUTH FLOW OPTIONS                        │
├─────────────────────────────────────────────────────────────┤
│  Option A: Email/Password Registration                      │
│  ───────────────────────────────────────                    │
│  POST /register → POST /verify-email → POST /login         │
│  JWT token in response                                      │
│                                                             │
│  Option B: OAuth2 Login (Google/Azure)                      │
│  ───────────────────────────────────────                    │
│  GET /oauth2/authorize/{provider} → redirect → callback     │
│  JWT token in redirect URL                                  │
│                                                             │
│  ⚠️ NOT INTERCHANGEABLE: email registered ≠ OAuth2 allowed  │
└─────────────────────────────────────────────────────────────┘
```

## 2. Email/Password Registration

### Step 1: Register

```
POST /api/v1/auth/register
Content-Type: application/json
```

**Request:**
```json
{
  "email": "user@student.edu.vn",
  "password": "SecurePass123!",
  "fullName": "Nguyen Van A"
}
```

**Password rules:**
- Tối thiểu 8 ký tự
- Có uppercase, lowercase, number, special character

**Response (200):**
```json
{
  "code": 200,
  "message": "Register request accepted. Please verify your email with OTP",
  "data": {
    "id": 1,
    "email": "user@student.edu.vn",
    "fullName": "Nguyen Van A",
    "status": "PENDING",
    "emailVerified": false,
    "notice": "Registration successful. Please verify your email with OTP."
  }
}
```

### Step 2: Verify Email

```
POST /api/v1/auth/verify-email
Content-Type: application/json
```

**Request:**
```json
{
  "email": "user@student.edu.vn",
  "otp": "123456"
}
```

**Response (200):**
```json
{
  "code": 200,
  "message": "Email verified successfully",
  "data": {
    "email": "user@student.edu.vn",
    "status": "ACTIVE",
    "emailVerified": true
  }
}
```

### Step 3: Login

```
POST /api/v1/auth/login
Content-Type: application/json
```

**Request:**
```json
{
  "email": "user@student.edu.vn",
  "password": "SecurePass123!"
}
```

**Response (200):**
```json
{
  "code": 200,
  "message": "Successfully logged in",
  "data": {
    "accessToken": "eyJhbGciOi...",
    "refreshToken": "eyJhbGciOi...",
    "expiresIn": 7200
  }
}
```

### Step 4: Use Token

```
GET /api/v1/users/me
Authorization: Bearer {accessToken}
```

## 3. OAuth2 Login (Google)

### Flow

```
1. FE redirect browser → http://localhost:3030/api/v1/auth/oauth2/authorize/google
2. Spring Security → redirect → Google login page
3. User login tại Google
4. Google callback → Backend → OAuth2SuccessHandler
5. JwtService.generateAccessToken() → JWT token
6. Redirect FE → http://localhost:3003/auth/success?access_token={jwt}
7. FE parse URL → store token → call API
```

### Step 1: Initiate Login

```typescript
// ✅ CORRECT - Browser redirect (NOT fetch/axios)
window.location.href = 'http://localhost:3030/api/v1/auth/oauth2/authorize/google';
```

### Step 2: Handle Callback

```typescript
// Trong component /auth/success
const params = new URLSearchParams(window.location.search);
const token = params.get('access_token');

if (token) {
  localStorage.setItem('jwt_token', token);
  // Navigate to dashboard
  navigate('/dashboard');
} else {
  // Handle error
  navigate('/login?error=oauth2_failed');
}
```

### Step 3: Use Token

```typescript
const token = localStorage.getItem('jwt_token');
const res = await fetch('http://localhost:3030/api/v1/users/me', {
  headers: { 'Authorization': `Bearer ${token}` }
});
```

## 4. ⚠️ OAuth2 Email Rejection Rules

### Rule: Email registered via /register CANNOT use OAuth2

```
User register with: user@student.edu.vn (email/password)
    ↓
Later: User try to login Google with same email
    ↓
❌ Backend reject: OAUTH2_EMAIL_ALREADY_REGISTERED (14001)
```

### Error Response:

```json
{
  "timestamp": 1743566166000,
  "code": 14001,
  "error": "Bad Request",
  "message": "Email already registered via email/password. Please login with email/password.",
  "path": "/login/oauth2/code/google"
}
```

### FE Handling:

```typescript
// Parse error from redirect URL
const error = params.get('error');
if (error === 'oauth2_failed') {
  const message = params.get('message');
  if (message?.includes('already registered')) {
    showError('Email này đã đăng ký bằng email/password. Vui lòng đăng nhập bằng email/password.');
    // Show email/password login form
    showLoginForm();
  }
}
```

## 5. Resend OTP

```
POST /api/v1/auth/resend-otp
Content-Type: application/json
```

**Request:**
```json
{
  "email": "user@student.edu.vn"
}
```

**Rate limits:**
- Cooldown: 60 giây
- Max resend: 5 lần per OTP window (15 phút)

**Error (429):**
```json
{
  "code": 6010,
  "message": "OTP resend is rate limited for email: user@student.edu.vn"
}
```

## 9. Error Handling

### Standard Error Format

```json
{
  "timestamp": 1743566166000,
  "code": 14001,
  "error": "Bad Request",
  "message": "Email already registered via email/password. Please login with email/password.",
  "path": "/login/oauth2/code/google"
}
```

### Auth-related Error Codes

| Code | HTTP Status | Message | Khi nào |
|------|-------------|---------|---------|
| 14001 | 400 | Email already registered via email/password | OAuth2 reject email đã register |
| 6001 | 404 | User not found | User không tồn tại |
| 6003 | 400 | Email already exists | Email trùng khi register |
| 6007 | 400 | Email already active | Email đã active, không đăng ký lại |
| 6009 | 400 | OTP invalid or expired | OTP sai hoặc hết hạn |
| 6010 | 429 | OTP resend rate limited | Resend quá nhanh |

### FE Error Handling Pattern

```typescript
const handleAuthError = (error: any) => {
  switch (error.code) {
    case 14001:
      showError('Email này đã đăng ký bằng email/password.');
      break;
    case 6003:
      showError('Email đã tồn tại trong hệ thống.');
      break;
    case 6009:
      showError('OTP không hợp lệ hoặc đã hết hạn.');
      break;
    case 6010:
      showError('Vui lòng chờ 60 giây trước khi gửi lại OTP.');
      break;
    default:
      showError(error.message);
  }
};
```

## 10. Provider List (Dynamic)

```
GET /api/v1/providers-config?isActive=true
```

**Response:**
```json
{
  "code": 200,
  "message": "Success",
  "data": [
    {
      "id": 1,
      "provider": "google",
      "displayName": "Google",
      "iconUrl": "https://www.google.com/favicon.ico",
      "sortOrder": 1,
      "isActive": true
    }
  ]
}
```

### FE Login Page Pattern

```typescript
const LoginPage = () => {
  const [providers, setProviders] = useState<Provider[]>([]);

  useEffect(() => {
    fetch(`${API_BASE_URL}/api/v1/providers-config?isActive=true`)
      .then(res => res.json())
      .then(result => setProviders(result.data));
  }, []);

  const handleProviderLogin = (providerCode: string) => {
    window.location.href = `${API_BASE_URL}/api/v1/auth/oauth2/authorize/${providerCode}`;
  };

  return (
    <div>
      {providers.map(p => (
        <button key={p.provider} onClick={() => handleProviderLogin(p.provider)}>
          <img src={p.iconUrl} alt={p.displayName} />
          Login with {p.displayName}
        </button>
      ))}
    </div>
  );
};
```

## 12. Common Mistakes to Avoid

| Mistake | Correct Approach |
|---------|-----------------|
| Dùng `fetch()` cho `/authorize/{provider}` | Dùng `window.location.href` redirect |
| Gọi `/login/oauth2/code/{provider}` trực tiếp | Spring Security tự handle |
| Expect JWT token trong response | Redirect FE với token trong URL |
| Lưu session cookie | Backend STATELESS — không session |
| Hardcode provider list | Fetch từ `/api/v1/providers-config` |
| Link email/password account với OAuth2 | Reject — không auto-link |
