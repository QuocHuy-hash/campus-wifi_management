## 1. Authentication APIs

### 1.1 Register (Email/Password)

**Endpoint:** `POST /auth/register`

**Request:**
```json
{
  "identifier": "user@example.com",
  "password": "Password123"
}
```

**Response (201):**
```json
{
  "code": 201,
  "message": "Register request accepted. Please verify your account with OTP",
  "data": {
    "userId": 1,
    "identifier": "user@example.com",
    "status": "PENDING"
  }
}
```

**Validation Rules:**
- Identifier: Email format (contains `@`) or phone (10-15 digits)
- Password: Min 8 characters, at least 1 digit

---

### 1.2 Verify OTP

**Endpoint:** `POST /auth/verify-otp`

**Request:**
```json
{
  "identifier": "user@example.com",
  "otp": "123456"
}
```

**Response (200):**
```json
{
  "code": 200,
  "message": "Account verified successfully",
  "data": {
    "identifier": "user@example.com",
    "status": "ACTIVE",
    "verified": true
  }
}
```

---

### 1.3 Resend OTP

**Endpoint:** `POST /auth/resend-otp`

**Request:**
```json
{
  "identifier": "user@example.com"
}
```

**Response (200):**
```json
{
  "code": 200,
  "message": "OTP resent successfully",
  "data": {
    "identifier": "user@example.com",
    "message": "OTP has been resent. Please check your email."
  }
}
```

---

### 1.4 Login (Email/Phone + Password)

**Endpoint:** `POST /auth/login`

**Request:**
```json
{
  "identifier": "user@example.com",
  "password": "Password123"
}
```

**Response (200):**
```json
{
  "code": 200,
  "message": "Successfully logged in",
  "data": {
    "accessToken": "eyJhbGciOiJIUzUxMiJ9...",
    "refreshToken": null,
    "roles": ["CAN_BO"]
  }
}
```

**Note:** 
- Access token in response body
- Refresh token in HttpOnly cookie (`refresh_token`)

---

|-------|------|-------------|

### 6.3 Create BANDWIDTH Policy

**Endpoint:** `POST /wifi-policies/bandwidth`

**Headers:** `Authorization: Bearer {accessToken}`

**Request:**
```json
{
  "name": "Băng thông Sinh viên",
  "description": "Giới hạn băng thông cho sinh viên",
  "isActive": true,
  "downloadLimit": 10,
  "uploadLimit": 5,
  "applyToRoles": ["SINH_VIEN"],
  "applyToArea": "Tòa A",
  "applyByTime": "8:00-17:00"
```

- `name`: Required, max 100 chars
- `downloadLimit`: Required, min 1, max 10000 (Mbps)
- `uploadLimit`: Required, min 1, max 10000 (Mbps)
- `applyToRoles`: Optional list of role names
- `applyToArea`: Optional
- `applyByTime`: Optional (format: "HH:mm-HH:mm" or "all")

**Response (201):**
```json
{
  "code": 201,
  "message": "Created successfully",
  "data": {
    "id": 1,
    "name": "Băng thông Sinh viên",
    "description": "Giới hạn băng thông cho sinh viên",

```

## Quick Reference

### Authentication Flow

```
1. Register → POST /auth/register
2. Verify OTP → POST /auth/verify-otp
3. Login → POST /auth/login → Get accessToken + refreshToken (cookie)
4. Call APIs → Header: Authorization: Bearer {accessToken}
5. Refresh → POST /auth/refresh-token (when accessToken expired)
6. Logout → POST /auth/logout
```

### Password Reset Flow

```
1. Forgot Password → POST /auth/forgot-password
2. Verify OTP → POST /auth/verify-reset-otp → Get token
3. Reset Password → POST /auth/reset-password
```

### OAuth2 Flow
```
1. Initiate → GET /api/v1/oauth2/google (or /api/v1/oauth2/azure)
2. User login at OAuth provider
3. Callback → Redirect {frontendUrl}/auth/success?access_token={jwt}
```
