# API Integration Guide - V1

## Base URL

```
http://localhost:3030
```

## Authentication

Hiện tại API chưa yêu cầu authentication cho các endpoints CRUD.

---

## Response Format

Tất cả responses đều có format chuẩn:

### Success Response

```json
{
  "statusCode": 200,
  "data": { ... },
  "message": "Success"
}
```

### Error Response

```json
{
  "timestamp": 1743123456789,
  "code": 1001,
  "error": "Not Found",
  "message": "WiFi controller not found with id: 999",
  "path": "/api/v1/wifi-controllers/999"
}
```

## Endpoints

### 1. Campus APIs

#### GET /api/v1/campus

Lấy danh sách tất cả các cơ sở.

**Response:**
```json
{
  "statusCode": 200,
  "data": [
    {
      "id": 1,
      "name": "Cơ sở Dĩ An",
      "code": "DA",
      "address": "123 Đường ABC, Dĩ An, Bình Dương",
      "description": "Cơ sở chính",
      "createdAt": "2026-03-28T10:00:00"
    }
  ],
  "message": "Success"
}
```

#### GET /api/v1/campus/{id}

Lấy chi tiết một cơ sở.

#### POST /api/v1/campus

Tạo mới cơ sở.

**Request Body:**
```json
{
  "name": "Cơ sở Dĩ An",
  "code": "DA",
  "address": "123 Đường ABC",
  "description": "Cơ sở chính"
}
```

#### PUT /api/v1/campus/{id}

Cập nhật cơ sở.

#### DELETE /api/v1/campus/{id}

Xóa cơ sở.

### 2. Buildings APIs

#### GET /api/v1/buildings

Lấy danh sách tất cả các tòa nhà.

#### GET /api/v1/buildings/{id}

Lấy chi tiết một tòa nhà.

#### POST /api/v1/buildings

Tạo mới tòa nhà.

**Request Body:**
```json
{
  "campusId": 1,
  "name": "Tòa nhà A",
  "totalFloors": 5,
  "description": "Tòa nhà ký túc xá"
}
```

#### PUT /api/v1/buildings/{id}

Cập nhật tòa nhà.

#### DELETE /api/v1/buildings/{id}

Xóa tòa nhà.

Tạo mới phòng/vị trí.

**Request Body:**

```json
  "buildingId": 1,
  "name": "Phòng A101",
  "code": "A101",

  "description": "Phòng học tầng 1"

```

#### PUT /api/v1/locations/{id}

Cập nhật phòng/vị trí.

#### DELETE /api/v1/locations/{id}

Xóa phòng/vị trí.

---

### 4. Wifi Controllers APIs

#### GET /api/v1/wifi-controllers

Lấy danh sách tất cả các WiFi Controller.

**Response:**
```json
{
  "statusCode": 200,
  "data": [
    {
      "id": 1,
      "nasIdentifier": "NAS-001",
      "ipAddress": "192.168.1.100",
      "sharedSecret": "secret123",
      "locationName": "Floor 1",
      "status": "ACTIVE",
      "createdAt": "2026-03-28T10:00:00"
    }
  ],
  "message": "Success"
}
```

#### GET /api/v1/wifi-controllers/{id}

Lấy chi tiết một WiFi Controller.

#### POST /api/v1/wifi-controllers

Tạo mới WiFi Controller.

**Request Body:**
```json
{
  "nasIdentifier": "NAS-001",
  "ipAddress": "192.168.1.100",
  "sharedSecret": "secret123",
  "locationName": "Floor 1",
  "status": "ACTIVE"
}
```

**Status values:** `ACTIVE`, `INACTIVE`

#### PUT /api/v1/wifi-controllers/{id}

Cập nhật WiFi Controller.

**Request Body:**
```json
{
  "locationName": "Floor 2",
  "status": "INACTIVE"
}
```

#### DELETE /api/v1/wifi-controllers/{id}

Xóa WiFi Controller.

---

### 5. Access Points APIs

#### GET /api/v1/access-points

Lấy danh sách tất cả các Access Point.

**Response:**
```json
{
  "statusCode": 200,
  "data": [
    {
      "macAddress": "00:1A:2B:3C:4D:5E",
      "apName": "AP-Floor1-01",
      "locationId": 1,
      "modelName": "Cisco AP-2800",
      "description": "Access point near reception",
      "createdAt": "2026-03-28T10:00:00"
    }
  ],
  "message": "Success"
}
```

#### GET /api/v1/access-points/{macAddress}

Lấy chi tiết một Access Point theo MAC address.

#### POST /api/v1/access-points

Tạo mới Access Point.

**Request Body:**
```json
{
  "macAddress": "00:1A:2B:3C:4D:5E",
  "apName": "AP-Floor1-01",
  "locationId": 1,
  "modelName": "Cisco AP-2800",
  "description": "Access point near reception"
}
```

**Lưu ý:** `locationId` phải tồn tại trong bảng locations.

#### PUT /api/v1/access-points/{macAddress}

Cập nhật Access Point.

**Request Body:**
```json
{
  "apName": "AP-Floor1-02",
  "locationId": 2,
  "description": "Updated description"
}
```

#### DELETE /api/v1/access-points/{macAddress}

Xóa Access Point.

## Error Codes

| Code | HTTP Status | Message |
|------|-------------|---------|
| 500 | 500 | Unexpected error occurred while processing request in backend service |
| 1001 | 404 | WiFi controller not found with id: {id} |
| 2001 | 404 | Access point not found with macAddress: {macAddress} |
| 2002 | 400 | Location not found with id: {id} |
| 3001 | 404 | Campus not found with id: {id} |
| 4001 | 404 | Building not found with id: {id} |
| 4002 | 400 | Campus not found with id: {id} |
| 5001 | 404 | Location not found with id: {id} |
| 5002 | 400 | Building not found with id: {id} |

---

## Validation Errors

Khi request validation thất bại (thiếu trường bắt buộc):

```json
{
  "timestamp": 1743123456789,
  "code": 400,
  "error": "Bad Request",
  "message": "nasIdentifier must not be blank",
  "path": "/api/v1/wifi-controllers"
}
```

## Quick Test Examples

### cURL Examples

```bash
# Get all campuses
curl -X GET http://localhost:3030/api/v1/campus

# Create campus
curl -X POST http://localhost:3030/api/v1/campus \
  -H "Content-Type: application/json" \
  -d '{"name": "Cơ sở Dĩ An", "code": "DA", "address": "123 ABC"}'

# Create building (requires campusId)
curl -X POST http://localhost:3030/api/v1/buildings \
  -H "Content-Type: application/json" \
  -d '{"campusId": 1, "name": "Tòa nhà A", "totalFloors": 5}'

# Create location (requires buildingId)
curl -X POST http://localhost:3030/api/v1/locations \
  -H "Content-Type: application/json" \
  -d '{"buildingId": 1, "name": "Phòng A101", "code": "A101", "floorNumber": 1}'

# Create wifi controller
curl -X POST http://localhost:3030/api/v1/wifi-controllers \
  -H "Content-Type: application/json" \
  -d '{"nasIdentifier": "NAS-001", "ipAddress": "192.168.1.100", "sharedSecret": "secret", "locationName": "Floor 1", "status": "ACTIVE"}'

# Create access point (requires locationId)
curl -X POST http://localhost:3030/api/v1/access-points \
  -H "Content-Type: application/json" \
  -d '{"macAddress": "00:1A:2B:3C:4D:5E", "apName": "AP-01", "locationId": 1, "modelName": "Cisco AP"}'
```
