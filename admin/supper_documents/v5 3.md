# API Integration Guide v5 - Frontend Developer

## Overview

**Base URL:** `http://localhost:3030/api/v1`

**Authentication:** Bearer JWT Token (2 hours) + Refresh Token Cookie (14 days)

**Content-Type:** `application/json`

**Response Wrapper:** All responses are wrapped in `ApiResponse<T>`:
```json
{
  "code": 200,
  "message": "Success",
  "data": { ... }
}
```

## 1. End-User Authentication APIs

**Base Path:** `/api/v1/auth`

### 1.1 Register (Email/Password)

**Endpoint:** `POST /api/v1/auth/register`

**Request Body:** `RegisterUserRequest`
```json
{
  "identifier": "user@example.com",
  "password": "Password123"
}
```

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| identifier | String | Yes | Email format (contains `@`) or phone (10-15 digits) |
| password | String | Yes | Min 8 characters |

**Response (200):** `ApiResponse<RegisterUserResponse>`
```json
{
  "code": 200,
  "message": "Register request accepted. Please verify your account with OTP",
  "data": {
    "id": 1,
    "email": "user@example.com",
    "fullName": "User Name",
    "status": "PENDING",
    "emailVerified": false,
    "createdAt": "2026-04-06T10:00:00Z",
    "notice": "OTP sent to your email"
  }
}
```

---

### 1.2 Verify OTP

**Endpoint:** `POST /api/v1/auth/verify-otp`

**Request Body:** `VerifyOtpRequest`
```json
{
  "identifier": "user@example.com",
  "otp": "123456"
}
```

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| identifier | String | Yes | Email or phone |
| otp | String | Yes | Exactly 6 digits |

**Response (200):** `ApiResponse<VerifyOtpResponse>`
```json
{
  "code": 200,
  "message": "Account verified successfully",
  "data": {
    "identifier": "user@example.com",
    "status": "ACTIVE",
    "verified": true,
    "message": "Account verified"
  }
}
```

### 1.4 Login (Email/Phone + Password)

**Endpoint:** `POST /api/v1/auth/login`

**Request Body:** `LoginRequest`
```json
{
  "identifier": "user@example.com",
  "password": "Password123"
}
```

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| identifier | String | Yes | Email or phone number |
| password | String | Yes | Min 8 characters |

**Response (200):** `ApiResponse<LoginResponse>`

**Cookie:** `refresh_token` (HttpOnly, SameSite=Strict, Path=/api/v1/auth/refresh-token, Max-Age=14 days)

```json
{
  "code": 200,
  "message": "Successfully logged in",
  "data": {
    "accessToken": "eyJhbGciOiJIUzUxMiJ9...",
    "refreshToken": null,
    "roles": ["CAN_BO"]
  }
}
```

**Note:** 
- `accessToken` is in the response body
- `refreshToken` is **always null** in response (stored in HttpOnly cookie)
- Cookie name: `refresh_token`

## 2. Admin Authentication APIs

**Base Path:** `/api/admin/auth`

### 2.1 Admin Login

**Endpoint:** `POST /api/admin/auth/login`

**Request Body:** `AdminLoginRequest`
```json
{
  "identifier": "admin",
  "password": "AdminPassword123"
}
```

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| identifier | String | Yes | Username (not blank) |
| password | String | Yes | Min 8 characters |

**Response (200):** `ApiResponse<AdminLoginResponse>`

**Cookie:** `admin_refresh_token` (HttpOnly, SameSite=Strict, Path=/api/admin/auth/refresh-token, Max-Age=14 days)

```json
{
  "code": 200,
  "message": "Login successful",
  "data": {
    "accessToken": "eyJhbGciOiJIUzUxMiJ9...",
```

```json
{
  "code": 401,
  "message": "Invalid credentials"
```

**Note:** 
- `refreshToken` is always null in response (stored in HttpOnly cookie)
- Cookie name: `admin_refresh_token` (different from user's `refresh_token`)

### 7.3 Create BANDWIDTH Policy

**Endpoint:** `POST /api/v1/wifi-policies/bandwidth`

**Headers:** `Authorization: Bearer {accessToken}`

**Request Body:** `CreateBandwidthPolicyRequest`
```json
{
  "name": "Băng thông Sinh viên",
  "description": "Giới hạn băng thông cho sinh viên",
  "isActive": true,
  "downloadLimit": 10,
  "uploadLimit": 5,
  "applyToRoles": ["SINH_VIEN"],
  "applyToArea": "Tòa A",
  "applyByTime": "8:00-17:00"
}
```

**Validation:**
- `name`: Required, max 100 chars
- `downloadLimit`: Required, min 1, max 10000 (Mbps)
- `uploadLimit`: Required, min 1, max 10000 (Mbps)
- `applyToRoles`: Optional list of role names
- `applyToArea`: Optional
- `applyByTime`: Optional (format: "HH:mm-HH:mm" or "all")

**Response (201):** `ApiResponse<WifiPolicyResponse>`

## Quick Reference

### End-User Authentication Flow

```
1. Register → POST /api/v1/auth/register
2. Verify OTP → POST /api/v1/auth/verify-otp
3. Login → POST /api/v1/auth/login → Get accessToken + refreshToken (cookie: refresh_token)
4. Call APIs → Header: Authorization: Bearer {accessToken}
5. Refresh → POST /api/v1/auth/refresh-token (uses cookie)
6. Logout → POST /api/v1/auth/logout
```

### Admin Authentication Flow

```
1. Login → POST /api/admin/auth/login → Get accessToken + refreshToken (cookie: admin_refresh_token)
2. Call APIs → Header: Authorization: Bearer {accessToken}
3. Refresh → POST /api/admin/auth/refresh-token (uses cookie)
4. Logout → POST /api/admin/auth/logout
```

### Password Reset Flow

```
1. Forgot Password → POST /api/v1/auth/forgot-password
2. Verify OTP → POST /api/v1/auth/verify-reset-otp → Get token
3. Reset Password → POST /api/v1/auth/reset-password
```

### OAuth2 Flow

```
1. Initiate → GET /api/v1/oauth2/google (or /api/v1/oauth2/azure)
2. User login at OAuth provider
3. Callback → Redirect {frontendUrl}/auth/success?access_token={jwt}
```
