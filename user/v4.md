## ⚠️ Breaking Change: GET /api/v1/users

### V3 → V4 Migration

| V3 | V4 | Ghi chú |
|----|----|----|
| `GET /api/v1/users` | ❌ Không còn trả `List<User>` raw | Đã thay đổi format |
| `GET /api/v1/users/by-roles?role=` | ❌ Endpoint này không còn tồn tại | Đã gộp |
| — | ✅ `GET /api/v1/users?role=` | Endpoint mới duy nhất |

### New Endpoint

```
GET /api/v1/users
GET /api/v1/users?role=STUDENT
GET /api/v1/users?role=STAFF_TEACHER
GET /api/v1/users?role=CLIENT
```

- `role` param là **optional**. Nếu omit → trả tất cả users
- Luôn trả `UserResponse` (có role, linkedAccounts, policies) — không còn raw `User` entity

## 1. GET /api/v1/auth/me — Lấy profile cá nhân

Trả về thông tin user đang đăng nhập, bao gồm danh sách OAuth providers đã liên kết.

```
GET /api/v1/auth/me
Authorization: Bearer {accessToken}
```

**Response (200):**
```json
{
  "code": 200,
  "message": "Success",
  "data": {
    "id": 1,
    "username": "user@student.edu.vn",
    "email": "user@student.edu.vn",
    "phone": null,
    "fullName": "Nguyen Van A",
    "avatarUrl": "https://...",
    "status": "ACTIVE",
    "emailVerified": true,
    "phoneVerified": false,
    "lastLoginAt": "2026-04-03T10:00:00Z",
    "createdAt": "2026-04-01T08:00:00Z",
    "linkedProviders": [
      {
        "provider": "google",
        "providerEmail": "user@gmail.com",
        "avatarUrl": "https://lh3.googleusercontent.com/...",
        "isActive": true,
        "linkedAt": "2026-04-02T09:00:00Z",
        "lastUsedAt": "2026-04-03T10:00:00Z"
      }
    ]
  }
}
```

**TypeScript interfaces:**
```typescript
// POST /login response
interface LoginResponse {

// POST /verify-otp response
interface VerifyOtpResponse {

  status: 'ACTIVE' | 'PENDING' | 'INACTIVE' | 'SUSPENDED';

  message: string;
}

interface LinkedProvider {
  provider: string;
  providerEmail: string | null;
  avatarUrl: string | null;
  isActive: boolean;

}

interface MeResponse {
  id: number;
  username: string;
  email: string | null;
  phone: string | null;
  fullName: string;

```

**React hook example:**
```typescript
const useMe = () => {
  const [profile, setProfile] = useState<MeResponse | null>(null);
  const token = localStorage.getItem('jwt_token');

  useEffect(() => {
    if (!token) return;
    fetch(`${API_BASE_URL}/api/v1/auth/me`, {
      headers: { Authorization: `Bearer ${token}` }
    })
      .then(res => res.json())
      .then(result => setProfile(result.data))
      .catch(console.error);
  }, [token]);

  return profile;
};
```

## 2. POST /api/v1/auth/change-password — Đổi mật khẩu

Dành cho user đăng ký bằng email/phone. **Social-only user (đăng nhập qua Google không có password) không dùng được endpoint này.**

```
POST /api/v1/auth/change-password
Authorization: Bearer {accessToken}
Content-Type: application/json
```

**Request:**
```json
{
  "currentPassword": "OldP@ss123",
  "newPassword": "NewP@ss456",
  "confirmPassword": "NewP@ss456"
}
```

**Response (200):**
```json
{
  "code": 200,
  "message": "Password changed successfully",
  "data": null
}
```

**Error cases:**

| Code | HTTP | Tình huống |
|------|------|-----------|
| 6004 | 400 | `currentPassword` sai |
| 6004 | 400 | `newPassword` ≠ `confirmPassword` |
| 6004 | 400 | User không có password (social-only) |
| 6001 | 404 | User không tồn tại |

**TypeScript:**
```typescript
interface ChangePasswordRequest {
  currentPassword: string;
  newPassword: string;      // min 8 ký tự
  confirmPassword: string;
}

const changePassword = async (data: ChangePasswordRequest): Promise<void> => {
  const token = localStorage.getItem('jwt_token');
  const res = await fetch(`${API_BASE_URL}/api/v1/auth/change-password`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${token}`
    },
    body: JSON.stringify(data)
  });

  const result = await res.json();
  if (result.code !== 200) {
    throw new Error(result.message);
  }
};
```

## 3. POST /api/v1/auth/link-provider — Liên kết OAuth2 Provider

Cho phép user đã đăng ký bằng email/phone **thêm đăng nhập qua Google** vào tài khoản hiện tại.

> ⚠️ **Lưu ý:** Endpoint này **KHÔNG phải** OAuth2 redirect flow. FE cần tự lấy `providerUserId` từ Google SDK (ví dụ Google Sign-In JS SDK hoặc `@react-oauth/google`), sau đó gọi API này với token.

```
POST /api/v1/auth/link-provider
Authorization: Bearer {accessToken}
Content-Type: application/json
```

**Request:**
```json
{
  "provider": "google",
  "providerUserId": "109876543000987654321",
  "providerEmail": "user@gmail.com",
  "avatarUrl": "https://lh3.googleusercontent.com/...",
  "accessToken": "ya29.A0AfH..."
}
```

| Field | Bắt buộc | Mô tả |
|-------|---------|-------|
| `provider` | ✅ | `"google"` hoặc `"azure"` |
| `providerUserId` | ✅ | `sub` (Google) hoặc `oid` (Azure) |
| `providerEmail` | ❌ | Email từ provider |
| `avatarUrl` | ❌ | Avatar URL từ provider |
| `accessToken` | ❌ | Access token từ provider |

**Response (200):**
```json
{
  "code": 200,
  "message": "Provider linked successfully",
  "data": null
}
```

**Error cases:**

| Code | HTTP | Tình huống |
|------|------|-----------|
| 12002 | 400 | Provider `google` đã được link cho user này |
| 12002 | 400 | `providerUserId` đã thuộc account khác |
| 6001 | 404 | User không tồn tại |

**TypeScript — Google Sign-In + Link Provider flow:**
```typescript
import { useGoogleLogin } from '@react-oauth/google';

interface LinkProviderRequest {
  provider: string;
  providerUserId: string;
  providerEmail?: string;
  avatarUrl?: string;
  accessToken?: string;
}

const useLinkGoogleProvider = () => {
  const token = localStorage.getItem('jwt_token');

  const linkGoogle = useGoogleLogin({
    onSuccess: async (tokenResponse) => {
      // Lấy user info từ Google
      const userInfo = await fetch('https://www.googleapis.com/oauth2/v3/userinfo', {
        headers: { Authorization: `Bearer ${tokenResponse.access_token}` }
      }).then(r => r.json());

      // Gọi API link-provider
      const res = await fetch(`${API_BASE_URL}/api/v1/auth/link-provider`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          Authorization: `Bearer ${token}`
        },
        body: JSON.stringify({
          provider: 'google',
          providerUserId: userInfo.sub,
          providerEmail: userInfo.email,
          avatarUrl: userInfo.picture,
          accessToken: tokenResponse.access_token
        } satisfies LinkProviderRequest)
      });

      const result = await res.json();
      if (result.code === 200) {
        alert('Đã liên kết Google thành công!');
      } else {
        alert(result.message);
      }
    },
    onError: () => alert('Google login thất bại')
  });

  return linkGoogle;
};
```

## 4. Error Codes mới trong V4

| Code | HTTP | Message | Khi nào |
|------|------|---------|---------|
| 6004 | 400 | Invalid password | Sai current password, hoặc new ≠ confirm, hoặc social user |
| 12002 | 400 | Provider config already exists | Provider đã link / providerUserId đã tồn tại |

Bảng đầy đủ tham khảo [v3.md - Section 9](./v3.md#9-error-handling).

## 6. Summary — V4 API Changes

| API | Method | Thay đổi |
|-----|--------|---------|
| `/api/v1/users` | GET | **Breaking** — format đổi sang `UserResponse`, có `?role=` filter |
| `/api/v1/users/by-roles` | GET | ❌ **Removed** — dùng `/api/v1/users?role=` thay thế |
| `/api/v1/auth/me` | GET | ✅ **New** — profile + linked providers |
| `/api/v1/auth/change-password` | POST | ✅ **New** — đổi mật khẩu |
| `/api/v1/auth/link-provider` | POST | ✅ **New** — liên kết OAuth2 provider |
